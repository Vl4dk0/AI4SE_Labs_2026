# Response alphabet

Every chat response may contain only these ASCII characters:

- lowercase letters `a` to `z` (ASCII 97 to 122)
- space (ASCII 32)
- newline (ASCII 10)

Nothing else is allowed in a response: no uppercase letters, digits, punctuation (`, . ? ! " ' : ; - ( )`), markdown symbols or emoji.
Write numbers as words.
This rule covers chat responses only. Files you write follow their own format.
