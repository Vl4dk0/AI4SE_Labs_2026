# Task 5: skill

Claude Code cita skills z `.claude/skills/<name>/SKILL.md` (projekt) alebo `~/.claude/skills/<name>/SKILL.md` (osobne).
V tomto repe je teraz `.claude/skills/crew/SKILL.md`. Je to moj vlastny skill na pustanie inych agent CLI (claude, gemini, grok, codex) ako subagentov cez command `crew`.
Vysvetluje ako spustit run, ako pustat background joby, ako zistit load stroja a quotu a ako zbriefovat subagenta. Pouzil som ho na Task 6.
