# Task 7 report

`dice_server.py` je maly MCP server s jednym toolom, `roll_dice(count, sides, modifier)`. Pouziva oficialne `mcp` SDK (FastMCP) cez stdio. Pydantic odmietne zly vstup, napriklad 0 kociek alebo d7. Skript si dependencies vypisuje sam (PEP 723), takze `uv run --script` ich nainstaluje a spusti bez nejakeho setupu. Subor `.mcp.json` v roote repa ho registruje pod menom `dice` pre tento projekt. Claude Code cita `.mcp.json` pri starte a server spusta ako child process. Kedze je to zdielany projektovy config, Claude Code sa pred spustenim servera pyta na schvalenie, a dovtedy `claude mcp list` ukazuje "Pending approval". `proof.md` ukazuje headless run, kde Claude zavolal tool a hodil 3d6+2 = 14. Ten run bezal s `--mcp-config .mcp.json`, co nacita server explicitne a schvalovaci prompt preskoci.
