Claude Code drzi user settings v `~/.claude/settings.json` a MCP servery plus stav uctu v `~/.claude.json`. Projekt moze pridat `.claude/settings.json`, `.claude/settings.local.json` a `.mcp.json`. Memory subory su `CLAUDE.md` (user a projekt). Vlastne veci byvaju v `.claude/commands`, `.claude/agents`, `.claude/rules` a `.claude/skills`.
Kazdy predchadzajuci task zmenil jeden subor. Task 1 zmenil `~/.claude/CLAUDE.md`. Task 2 pridal `.claude/commands/beer.md`. Task 3 pridal `AGENTS.md` a `CLAUDE.md`. Task 4 pridal `.claude/agents/web_browser.md`. Task 5 pridal `.claude/skills/crew`. Task 7 pridal `.mcp.json`. Task 8 pridal `.claude/rules/lowercase-only.md`.
Priecinok `config/` obsahuje kopie settings suborov. Tento projekt nema `.claude/settings.json`, takze ziadny nie je skopirovany. V suboroch neboli ziadne kluce ani tokeny.
